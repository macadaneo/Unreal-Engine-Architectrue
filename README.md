# Unreal Engine Architectrue 
Game Engine Architecture I introduces students to real-time interactive development through Unreal Engine 5 and its Blueprint visual scripting system. This course serves as students’ first deep engagement with Unreal, focusing on building functional gameplay systems, integrating assets from prior modeling and animation courses, and developing a complete low‑poly game prototype over the semester. Students will learn to construct modular gameplay logic, manage data and assets efficiently, and produce polished interactions using visual scripting, animation, audio, and environment tools. Houdini will be incorporated as a procedural asset pipeline to support scalable production workflows.  The course emphasizes practical, iterative development: students will submit a playable Blueprint-driven game by the end of the semester and document their production process through milestone submissions and a final portfolio.
